### Tauri stall diagnosis (2026-09-11)

The unrecorded switch stall reproduced with footprint sampling disabled and with a per-open ReadyTranscript key. Temporary bootstrap tracing showed `document.visibilityState === "hidden"`, then all JavaScript heartbeat events stopped before the switched open reached native code. At the same time `CGSessionCopyCurrentDictionary` reported `CGSSessionScreenIsLocked = true`, and `NSWorkspace` reported `com.apple.loginwindow` as foreground. ScreenCaptureKit still enumerated display 23. This is a locked-desktop confound, not evidence of slow native Tauri parsing. The launch helper and runner now reject locked/non-console sessions without retries and invalidate a launch if the session locks during it. Production tracing was removed. Repeated unlocked verification and the full comparable table remain pending.

The user requested skipping Tauri and continuing the other eight while locked, as prior recordings worked in that state. Added explicit `--allow-locked-session` with per-observation lock metadata and `--launch-attempts 1`; foreground equivalence remains unverified, but a blanket rejection of every framework was broader than the evidence.
